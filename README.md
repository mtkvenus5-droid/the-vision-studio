# The Vision Studio

Agência de Branding, Design e Produção Visual Premium.

## 📋 Visão Geral

The Vision Studio é uma plataforma digital moderna e profissional desenvolvida em **Next.js**, apresentando serviços de branding estratégico, design digital e produção visual de alto impacto.

## 🚀 Recursos Principais

- ✨ **Homepage Premium** com design moderno e responsivo
- 📱 **Design Totalmente Responsivo** para todos os dispositivos
- 📧 **Formulário de Contato** integrado com WhatsApp automático
- 🎨 **Identidade Visual Forte** com paleta premium
- ⚡ **Performance Otimizada** para Vercel
- 🔍 **SEO Amigável** com metadados estruturados
- 📞 **Integração com WhatsApp e Instagram**
- 🎯 **Chamadas para Ação** estratégicas

## 🛠 Tecnologias Utilizadas

- **Next.js 14** - Framework React moderno
- **TypeScript** - Tipagem estática
- **CSS3** - Estilização moderna
- **Vercel** - Deploy otimizado

## 📦 Instalação Local

### Pré-requisitos
- Node.js 18+
- npm ou yarn
- Git

### Passos

1. **Clone o repositório**
   ```bash
   git clone https://github.com/mtkvenus5-droid/the-vision-studio.git
   cd the-vision-studio
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Configure variáveis de ambiente**
   ```bash
   cp .env.example .env.local
   ```

4. **Rode desenvolvimento**
   ```bash
   npm run dev
   ```

5. **Acesse**
   ```
   http://localhost:3000
   ```

## 🏗 Build para Produção

```bash
npm run build
npm start
```

## 🌐 Deploy no Vercel

### Via Web (Recomendado)
1. Acesse [vercel.com](https://vercel.com)
2. Clique "Add New Project"
3. Selecione repositório GitHub
4. Vercel detectará Next.js automaticamente
5. Clique "Deploy"

### Via CLI
```bash
npm install -g vercel
vercel
```
